登录

登录后可以发文章、传歌、评论

2~20 个字符，注册后不能改
至少 6 位，会用 PBKDF2 加盐哈希后入库

还没有账号？注册一个

正在编辑： 改完点「更新文章」，不会影响浏览数

全部文章

删除会同时清掉数据库记录和它的评论，无法恢复，删之前请确认。

上传歌曲

mp3 / m4a / aac / wav / ogg / flac，单个最大 50MB
可选，会显示成黑胶唱片的样子

曲库

不手动指定时，首页会按日期在所有歌曲里自动轮换；想让某天固定推某一首，就选日期点「设为推荐」。

我的资料

jpg / png / webp / gif，显示成圆形；不传就用昵称首字
昵称会显示在文章、评论和顶栏上

全部用户

被禁言的用户不能再发表评论，但仍然可以浏览网站、播放歌曲。 别人发的文章和评论你随时可以删除 —— 在「文章管理」里，或直接到文章页的评论区点删除。

主题配色

选好颜色后点「保存配色」。整站的颜色都会跟着变 —— 按钮、链接、卡片光晕、连背景的极光渐变也是。 调色时会立刻在页面上看到效果，不用来回切换。

主色 · 按钮与链接
辅色 · 渐变另一端
点缀色 · 标题渐变末尾

网站背景图

支持 jpg / png / webp / gif。建议用 1920×1080 以上的横图， 文件控制在 5MB 以内 —— 图越大，访客打开首页越慢
背景图上会盖一层黑色遮罩。数值越小背景照片越清楚，越大则文字越突出。
实测建议 50~70：这个区间里照片看得清、文字也不吃力。 照片本身很亮很花（比如白天风景）就往 70 以上调； 照片偏暗（夜景、深色抽象图）就调到 40 左右，否则整张图会糊成一片黑。
